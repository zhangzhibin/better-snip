# Simple Snip

Support for the macOS screenshot app.

## What it does

Simple Snip only takes screenshots. It runs on macOS 12 or later, from the menu bar, and does not need a network connection.

- Press ⌘⌥C, or choose Capture from the menu bar.
- Drag a region, or hover a window and click.
- Annotate, then save to the clipboard, a file, or both.

## Screen Recording

macOS requires Screen Recording permission. Open Preferences from the menu bar. If the status is not Granted, choose Grant Access and allow Simple Snip in System Settings. Then quit the app and open it again.

# Simple Snip

macOS 截图应用的技术支持。

## 它做什么

Simple Snip 只做截图。它在 macOS 12 或更高版本上运行，从菜单栏打开，不需要联网。

- 按 ⌘⌥C，或从菜单栏选择 Capture。
- 拖选区域，或悬停在窗口上后单击。
- 标注后保存到剪贴板、文件，或两者都保存。

## 屏幕录制

macOS 需要「屏幕录制」权限。从菜单栏打开 Preferences。如果状态不是 Granted，点 Grant Access，并在系统设置里允许 Simple Snip。然后退出应用，再打开一次。
